## Featured project

### SignMate — English-to-British Sign Language translation prototype

For my final-year Computer Science group project, I worked on **SignMate**, an application designed to convert English text into British Sign Language (BSL) gloss sequences and support avatar-based presentation.

My contributions included:
- Developing rule-based natural language processing and context-recognition components.
- Preparing sign-language data for lookup and animation workflows.
- Integrating translation functionality with the application backend and user interface.
- Contributing to the technical design and integration of the prototype.

The team chose a rule-based approach after considering the scope and practicality of a machine-learning approach for the project.
